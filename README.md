# สมุดรับจ่าย

เว็บบันทึกรายรับรายจ่าย แนบรูปสลิป แยกหมวดหมู่ และสรุปรายเดือน
ข้อมูลเก็บบน Firebase (Firestore แพ็กเกจฟรี Spark) ล็อกอินด้วย Google หรืออีเมลและรหัสผ่าน

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเว็บ |
| `firebase-config.js` | ค่าเชื่อมต่อโปรเจกต์ Firebase (ต้องแก้) |
| `firestore.rules` | กฎความปลอดภัย (แก้อีเมล แล้วนำไปวางใน Firebase) |
| `icons/` | ไอคอนเว็บ |

---

## 1. ตั้งค่า Firebase
1. ไปที่ https://console.firebase.google.com → Create a project (ปิด Google Analytics ได้)
2. **Authentication** → Get started → แท็บ Sign-in method แล้วเปิดแบบที่ต้องการ (เปิดทั้งสองแบบก็ได้)
   - **Google** → Enable → เลือก Project support email → Save
     ล็อกอินด้วย Google ได้เลยโดยไม่ต้องสร้างบัญชีล่วงหน้า
   - **Email/Password** → Enable → Save
     จากนั้นไปที่แท็บ Users → **Add user** ใส่อีเมลและรหัสผ่าน (เว็บไม่มีปุ่มสมัคร)
3. **Firestore Database** → Create database → Location `asia-southeast1 (Singapore)` → Production mode
4. Firestore → แท็บ **Rules** → วางเนื้อหาจาก `firestore.rules` เปลี่ยน `your-email@example.com` เป็นอีเมลของคุณ (ถ้าใช้ Google ให้ใส่อีเมล Gmail นั้น) → Publish
5. ⚙️ Project settings → Your apps → ไอคอนเว็บ `</>` → Register app → คัดลอกค่าใน `firebaseConfig` มาวางใน `firebase-config.js`

> ค่าใน `firebase-config.js` ไม่ใช่รหัสลับ อัปขึ้น GitHub แบบสาธารณะได้
> ความปลอดภัยมาจากกฎในข้อ 4 ซึ่งให้เฉพาะอีเมลของคุณอ่านและเขียนข้อมูลได้
> ใครล็อกอินด้วยบัญชี Google อื่น จะเห็นข้อความว่าไม่มีสิทธิ์เข้าถึง

## 2. Deploy ด้วย GitHub Pages
1. สร้าง repository ใหม่บน GitHub (เช่น `slip-ledger`)
2. กด **Add file → Upload files** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ไปวาง (รวมโฟลเดอร์ `icons`) → Commit
3. ไปที่ **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/slip-ledger/`
5. กลับไปที่ Firebase → Authentication → **Settings → Authorized domains** → Add domain → ใส่ `ชื่อผู้ใช้.github.io`
   (จำเป็นสำหรับการล็อกอินด้วย Google ถ้าไม่เพิ่ม จะล็อกอินไม่ได้)

ต่อไปถ้าแก้ไฟล์ใน GitHub แล้ว commit เว็บจะอัปเดตเองภายในไม่กี่นาที

## 3. ใช้บนมือถือ
เปิดลิงก์ในเบราว์เซอร์ได้เลย (การล็อกอินด้วย Google จะเปิดหน้าต่างใหม่ ถ้าถูกบล็อก ให้อนุญาตป๊อปอัปสำหรับเว็บนี้) ถ้าอยากมีไอคอนบนหน้าจอ:
iPhone ใช้ Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม / Android ใช้ Chrome → ⋮ → เพิ่มลงในหน้าจอหลัก

## ข้อมูลเดิม
ถ้ามีข้อมูลจากเวอร์ชันก่อน ให้กด "สำรองเป็นไฟล์" จากเวอร์ชันเดิม แล้วในเว็บนี้ไปที่ รายการ → ตั้งค่า → กู้คืนจากไฟล์
(ถ้าเปิดที่โดเมนเดียวกับเวอร์ชันเดิม จะมีปุ่ม "ย้ายข้อมูลขึ้นบัญชี" ให้กดได้เลย)

## โควตาฟรีโดยประมาณ
Firestore 1 GB, อ่าน 50,000 ครั้ง/วัน, เขียน 20,000 ครั้ง/วัน
รูปสลิปถูกย่อเหลือประมาณ 100–300 KB ต่อใบ ใช้คนเดียวเก็บได้หลายพันใบ ใช้เกินโควตาจะหยุดชั่วคราวจนถึงวันถัดไป ไม่มีค่าใช้จ่าย

## ถ้าเคยใช้บัญชีอีเมล/รหัสผ่านมาก่อน
ถ้าล็อกอินด้วย Google โดยใช้อีเมลเดียวกับบัญชีอีเมล/รหัสผ่านที่สร้างไว้ Firebase จะเปลี่ยนบัญชีนั้นไปใช้ Google แทน และรหัสผ่านเดิมจะใช้ไม่ได้อีก
ข้อมูลควรยังอยู่ แต่แนะนำให้กด "สำรองเป็นไฟล์" ไว้ก่อนเปลี่ยนวิธีล็อกอิน
